# OSGARD PREMIUM SEVEN V13 — полная проверка исходных материалов

## Что изменено

Ранее V12 сверяла исходные изображения всех проектов по SHA-256, но у шести нативных страниц HTML, JavaScript и CSS принимались без сравнения с утверждёнными байтами. Это допускало ложный PASS при изменённом HTML с правильным логотипом.

V13 проверяет **41 файл для 7 продуктов**: по одному HTML, JavaScript и CSS плюс два WebP для SUPER DAY; для шести остальных также shell.css. Для HTML закреплены точные SHA-256 из архивов V9/V10/V11, для JS/CSS — хеши утверждённого общего runtime, для shell.css — хеш V9, для WebP — фактические локальные хеши, дополнительно сверяемые с V9 RELEASE_MANIFEST.json.

Скрипт inventory-premium-domains.mjs сначала проверяет закреплённые оригиналы и происхождение, затем загружает публичные страницы и сверяет их HTTP-статусы, MIME, целевые URL, HTML-маркеры и все SHA-256. Если хотя бы один файл изменён или отсутствует эталонный хеш, продукт не считается опубликованным.

## Источники и ограничения

- SUPER DAY: подтверждённая GitHub Pages публикация; оригинальный центральный V9.
- NEW WORLD: index.html из PR #259 в HADJAL001/asgard-redesign, Git blob f35fca2e43d06219cd9b47d5a6fbe690d556dbdb. PR пока не объединён.

- OSGARDOS: index.html из основного HADJAL001/osgardos, Git blob c922820754c3e329313b78c30b585a80fd17c150.
- MYOSA: index.html из PR #1 HADJAL001/osa, Git blob 7d5dea2d2a1fa2a23961009c2f348f985dcc7053. PR пока не объединён.
- SENJORIO/VANGUARD: утверждённые V11 staging-файлы, исходные репозитории не установлены; статус staging_only сохранён в манифесте.

Реальный runtime не заменяется визуальной страницей. Ничего не публикуется на шести внешних доменах этим PR. Проверка статики не доказывает работоспособность авторизации, платежей, нейросети, бронирования поездок и серверных API.

## Тестирование и выпуск

Команда: node --test scripts/premium-domain-attestation.test.mjs scripts/premium-source-pinning.test.mjs

Команда: node scripts/inventory-premium-domains.mjs (требует внешнего HTTPS; read-only).

Цель: 23 регрессионных теста, ежедневное 09:00 UTC без отключения прежних проверок и новый OSGARD_PREMIUM_V13_DOMAINS.json. Рядом продолжают генерироваться V12/V9 JSON для совместимости.

Изменения утверждённых SHA должны проходить отдельный PR с точными исходниками, реальными Git-идентификаторами и регрессионными скриншотами. Запрещено подменять некорректные ответы сервера фиктивным PASS.

Серверная публикация MYOSA, O2 SYSTEM, OSGARDOS, NEW WORLD, SENJORIO и VANGUARD остаётся отдельным этапом, пока не подтверждена независимым HTTPS-аудитом и основными пользовательскими сценариями.
