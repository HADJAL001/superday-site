# OSGARD PREMIUM SEVEN · V9

Утверждённая владельцем галерея семи продуктов: MYOSA / OSGARD NEW WORLD / OSGARDOS / SENJORIO / VANGUARD / SUPER DAY / O2 SYSTEM.

**Точное визуальное ядро V7 сохранено**, WebP экспортированы без потери байтов. Сетка 2+2+3, темы A/B, поиск Ctrl+K, локальные инструменты и переходы между страницами.

## Структура

- `index.html` — стартовая галерея и 7 детальных маршрутов `?product=slug`
- `app.js`, `workspace.js`, `styles.css` — исходный код, вынесенный из монолитного HTML
- `assets/` — 28 оригинальных WebP, 14 для карточек и 14 для детальных страниц
- `PREVIEW_*.html` — 7 совместимых кратких ссылок
- `RELEASE_MANIFEST.json`, `QA_REPORT.json`, `CHANGELOG.md`, `DEPLOYMENT.md`, `PRODUCTION_BOUNDARIES.md`

## Запуск и тест

```bash
python3 -m http.server 8080 --directory .
# http://localhost:8080/premium-ab-preview/
python3 qa/test_v8.py
```

## Граница готовности

Работает реальный браузерный демонстрационный интерфейс с данными, сохраняемыми **только локально**. Это НЕ production-код семи сервисов: недоступны реальная авторизация, биллинг, бронирование, проведение финансовых операций, AI-рендеринг.

Числа, написанные на концепт-изображениях, — элементы художественного макета, а не проверенные бизнес-показатели.

## V9: вход в приложения

Серверные API, авторизация и данные клиентов **не перенесены**. Добавлены отдельные стилистические страницы для трёх подтверждённых рабочих репозиториев. Пользователь запускает настоящий сервис по кнопке «Открыть приложение». `PREVIEW_ALL.html` — совместимый путь без ошибки 404.
