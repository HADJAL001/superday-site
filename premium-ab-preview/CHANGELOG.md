# OSGARD PREMIUM SEVEN — Changelog

## V8.0.0 (2026-10-26)
- Восстановлены и сохранены **все 28 исходных WebP** из подтверждённой V7 — без генерации и изменения графики.
- Вместо HTML на 2,6 МБ: отдельные CSS, JS, 28 WebP и HTML. Браузер использует кэш, каждая тема быстро переключается.
- Две независимые исходные темы A/B и точная сетка 2+2+3 сохранены.
- Статический CSP запрещает внешние сетевые запросы от демонстрации.
- Добавлена настоящая HTTP- и browser-QA приёмка с проверкой путей, 7 продуктов, переключения A/B, мобильных размеров, клавиатуры, локальных инструментов и отсутствия 404.
- Зафиксирован реестр SHA-256 исходных WebP и версия V7 → V8.
- Публикация проводится ТОЛЬКО по пути `premium-ab-preview/` в существующем репозитории, без изменения работающего приложения.

## V7.0.0 (2026-10-26)
