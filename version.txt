SUPER DAY — метка версии развёрнутого содержимого.

Один и тот же репозиторий публикуется на трёх независимых площадках:
  * GitHub Pages — superday.fun (основная, для пользователей);
  * Netlify — резервная публикация той же статики;
  * кластер OSGARD — superday.osgard.cloud (собственная инфраструктура,
    образ собирается из Dockerfile в корне репозитория).

Файл существует ради проверяемости: по нему видно, какое именно содержимое
сейчас отдаёт каждая площадка, без догадок по внешнему виду страницы.

Контур «коммит в репозиторий → прод на кластере OSGARD» замкнут 2026-07-28.
